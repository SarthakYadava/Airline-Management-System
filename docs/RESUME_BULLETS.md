# SkyRoute Resume Bullets

Choose three or four bullets that best match the role:

- Built a full-stack airline management platform with React, TypeScript,
  Node.js, Express, MySQL, Sequelize, and five independently structured backend
  services.
- Developed flight search, JWT-based authentication, booking history, and an
  administrator dashboard for managing cities, airports, aircraft, and flight
  schedules.
- Prevented seat overselling by implementing transactional inventory updates
  with row locking and compensating seat releases when booking persistence
  fails.
- Implemented asynchronous booking notifications with RabbitMQ publisher
  confirms, a durable exchange and queue, consumer acknowledgements, and
  scheduled email status tracking.
- Improved API reliability with request validation, consistent error
  responses, paginated and sortable flight search, protected administrator
  routes, and internal service authentication.
- Added 42 automated backend tests covering authentication, booking workflows,
  race-safe inventory, management validation, event publication, and queue
  consumption.
- Created a responsive traveler interface with flight comparison cards, route
  visualization, account flows, booking confirmation, trip history, and
  desktop and mobile layouts.
- Prepared reproducible local and containerized environments with database
  migrations, demo seed data, health checks, Dockerfiles, Docker Compose, and
  CI build verification.
